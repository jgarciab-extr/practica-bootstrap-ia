# 📐 Reglas de Diseño del Proyecto (project.md)

## 🎨 Paleta de Colores Autorizada (Bootstrap Nativo)
- Fondo Principal del Bloque Hero: Clase `bg-dark` con texto `text-white`.
- Fondo de las Tarjetas de Servicio: Clase `bg-light` con texto `text-dark`.
- Enlaces y Elementos Resaltados: Clase `text-info`.

## 🏗️ Normas de Construcción
1. La pantalla se dividirá en secciones proporcionales utilizando exclusivamente las columnas del Grid de Bootstrap (`col-md-6`).
2. Queda totalmente prohibido escribir etiquetas `<style>` personalizadas o propiedades inline como `style="..."`. Todo el diseño debe ser 100% Bootstrap nativo.
